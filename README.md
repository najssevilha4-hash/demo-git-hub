# Processamento remoto de vendas 
Projeto desenvolvido na UFCD 10806 — Linguagens de scripting e linha de comandos.
 ## Objetivo Enviar dados e scripts para um repositório GitHub, executar o processamento através do GitHub Actions e descarregar o relatório produzido.

## Estrutura 
- dados: ficheiros CSV 
- scripts: scripts Bash 
- resultados: relatórios produzidos 
- logs: registos da execução 
- .github/workflows: automatização do GitHub Actions
